# 美术方向（试点）

合成题材，不绑定任何在售/朋友项目 IP。

## 画风锚点

- 2D 手绘感、平面色块、粗外轮廓
- 低饱和、限制色板（约 8–10 色）
- 单主体先读，机制信息后读
- 避免：大面积霓虹、写实摄影感、复杂金边、人脸

## 三个合成角色（串行）

| ID | 题材 | 验证点 |
|----|------|--------|
| `stone-relic` | 低饱和石片遗物，一枚暖色刻痕 | 轮廓、材质、150px、键色背景 |
| `stick-runner` | 火柴人奔跑姿态 | 姿态选项 → 选定 1 个再生成 |
| `energy-token` | 圆形能量符石，冷色核心 | 与 relic 同载体换色的配对感 |

## 生图约束（当前 MiMo）

- `background: opaque`；透明直出不可用
- 主体外用纯品红 `#FF00FF` 便于 chroma-key（policy 里已配置）
- 平台右下角 AI 水印：不抠不裁作为卖点；正式资产勿依赖
- 画布最终对齐到 **256×256**（`align-canvas`）

见 `review/rules.yaml`。缩到 150×150 后：先认出主体，再认出机制标记。
